# دليل تشغيل الأرشيف الذكي محلياً (أوفلاين بالكامل) باستخدام Docker 🐳

تم تصميم وتطوير هذه الإضافة لتمكينك من تشغيل المنظومة بالكامل **دون الحاجة للاتصال بالإنترنت أو الاعتماد على سحابة Firebase**. يتم حفظ البيانات والوثائق والملفات الممسوحة ضوئياً مباشرة على القرص الصلب الخاص بجهازك بشكل آمن وتلقائي.

---

## 🏗️ كيف يعمل النظام أوفلاين؟

1. **قاعدة البيانات المحلية (JSON DB):** تم إدراج محرك تخزين محلي يعتمد على ملفات JSON (`documents.json` و `categories.json`) يتم تخزينها وتحديثها تلقائياً داخل مجلد `/app/data` في الكانتينر.
2. **مجلد حفظ الملفات:** يتم تخزين الصور والملفات الممسوحة مباشرة على القرص.
3. **مزامنة ثنائية الاتجاه:** بمجرد تشغيل **"وضع الأوفلاين (محلي)"** من واجهة البرنامج، سيتوقف الاتصال السحابي بـ Firebase تماماً، وسيقوم المتصفح بقراءة وحفظ كافة البيانات والملفات من الملقم المحلي لـ Docker مباشرة.
4. **الذكاء الاصطناعي المحلي (Ollama):** يتكامل النظام تلقائياً مع خادم Ollama المحلي لتحليل النصوص واستخراج البيانات الذكية دون إرسال أي حرف خارج شبكتك المحلية.

---

## 📋 متطلبات التشغيل

* تثبيت برنامج **Docker Desktop** على جهازك (لويندوز، ماك، أو لينكس).
* (اختياري) تثبيت **Ollama** على جهازك مباشرة، أو استخدام خادم Ollama المرفق في ملف `docker-compose`.

---

## 🚀 خطوات التشغيل بضغطة زر واحدة

افتح نافذة الأوامر (Terminal أو CMD) في مجلد المشروع ونفذ الأوامر التالية:

### 1. تشغيل الخدمات (البرنامج + خادم الذكاء الاصطناعي)
```bash
docker-compose up -d --build
```
*سيقوم هذا الأمر ببناء تطبيق الأرشيف الذكي وتشغيله على المنفذ `3000` وتشغيل Ollama على المنفذ `11434`.*

### 2. تحميل نموذج الذكاء الاصطناعي المحلي (مرة واحدة فقط)
لتتمكن من استخراج وتصنيف الكتب الإدارية تلقائياً وبدقة عالية باللغة العربية، قم بتحميل نموذج `qwen2.5:7b` (أو أي نموذج آخر تفضله):
```bash
docker exec -it archiver_ollama_server ollama run qwen2.5:7b
```
*(بمجرد اكتمال التحميل، يمكنك إغلاق نافذة الأوامر والبدء بالاستخدام).*

---

## 📁 أين تحفظ ملفاتي وبياناتي؟

عند تشغيل الكانتينر، سيقوم Docker تلقائياً بإنشاء مجلد محلي باسم:
👉 **`archiver-data`** بجوار ملف المشروع مباشرة.

يحتوي هذا المجلد على:
* 📂 **`documents.json`**: قاعدة بيانات كافة الكتب والوثائق المؤرشفة وحقولها.
* 📂 **`categories.json`**: قائمة المجلدات والتصانيف المخصصة التي قمت بإنشائها.
* 📂 **`files`**: يحتوي على كافة ملفات الصور والـ PDF الخاصة بالكتب الإدارية التي قمت برفعها أو مسحها ضوئياً.

> ⚠️ **ملاحظة أمنية هامة:** لا تقم بحذف مجلد `archiver-data` لأن جميع بياناتك المؤرشفة محفوظة بداخله. يمكنك أخذ نسخة احتياطية من هذا المجلد في أي وقت لحماية بياناتك.

---

## ⚙️ إعدادات واجهة المستخدم للأوفلاين

1. افتح المتصفح واذهب إلى الرابط: **`http://localhost:3000`**
2. من الشريط العلوي، قم بالضغط على زر **"متصل بالسحابة"** ليتحول إلى **"وضع الأوفلاين (محلي)"**.
3. اذهب إلى **إعدادات الماسح والمعالجة** (Settings):
   * قم بتفعيل خيار **"تفعيل Ollama للتحليل والفرز الذكي"**.
   * تأكد من أن الرابط هو: `http://localhost:11434` (أو `http://host.docker.internal:11434` إذا كان Ollama مثبتاً خارج دكر).
   * اكتب اسم النموذج المستخدم: `qwen2.5:7b`.

الآن، أصبح لديك أرشيف مستندات متكامل، آمن، فائق السرعة، ومحمي بنسبة 100% داخل شركتك أو منزلك دون أي حاجة للإنترنت! 🎉
